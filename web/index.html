          网络与更新
          
        

        
GitHub 官方源在国内可能无法直连。更新失败时本工具会自动回退到镜像站（ghfast.top / ghproxy / Gitee 等）下载模板与 nuclei 二进制，无需手动配置。

        
点击「检测网络连通性」查看各源可达性。

        

          
          
          
          
        

        

      

      

        
数据备份与恢复
